# UI implementation rules

For new or redesigned tables and operational record lists, follow the
“Tables and mobile record lists” section of `docs/design-system.md`.
Use `/admin/horarios` as the section-style reference and `/tareas` for the
desktop-table/mobile-list adaptation. Reuse `ElevatedSurface`, `ListToolbar`,
and `FilterBar`/`FilterChip`; use shared color tokens, inset dividers, and
mobile record lists with labeled fields. Place primary CTAs in the page header.
